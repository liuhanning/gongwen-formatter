# 公文格式化工具 (Gongwen Document Formatter)

专业的 Word 文档自动化排版工具（VBA宏版本），符合 **GB/T 9704 党政机关公文格式规范** 和 **政府交付版格式标准**。

## ✨ 功能特点

- ✅ **双模式支持**：GB/T 9704标准模式 + 政府交付版模式
- ✅ **完全符合规范**：严格遵循标准的 7 项格式要求
- 🚀 **一键格式化**：自动识别标题级别，智能应用格式
- 🔧 **字体兼容**：自动检测并退化到可用字体
- 💼 **WPS兼容**：完美支持 WPS Office 和 Microsoft Word

## 🎯 格式模式说明

### 模式一：GB/T 9704标准模式（默认）
- **标题缩进**：二、三、四级标题使用**左缩进2字符**
- **适用场景**：传统公文格式，符合GB/T 9704-2012标准

### 模式二：政府交付版模式
- **标题缩进**：二、三、四级标题使用**首行缩进2字符**
- **适用场景**：政府部门交付文档，咨询报告等
- **新增要求**：文档网格对齐

## 📋 格式规范（7项要求）

### 1. 页面设置
- A4 版幅（210mm × 297mm）
- 上边距：3.7cm，下边距：3.5cm
- 左边距：2.8cm，右边距：2.6cm
- 页眉页脚：均为 1.8cm

### 2. 标题格式
- **一级标题**：方正小标宋简体二号，30磅行距，居中
- **二级标题**：黑体三号，30磅行距，左缩进/首行缩进2字符
- **三级标题**：楷体_GB2312三号，30磅行距，左缩进/首行缩进2字符
- **四级及以下**：仿宋_GB2312三号，28磅行距，左缩进/首行缩进2字符

### 封面识别规则
- 扫描文档前 30 段，忽略空行和表格内容
- 仅收集前部短正文段落（长度 <= 100）作为封面候选
- 从后向前识别日期段
- 在日期前优先识别编制单位段
- 编制单位前的所有候选段统一视为封面标题，支持多行标题

#### 日期识别支持
- `2026 年 4 月`
- `2026 年 4 月 15 日`
- `2026-04`
- `2026/04`
- `2026.04`

#### 编制单位识别
- 优先匹配机构特征词，如 `公司`、`咨询`、`研究院`、`研究所`、`中心`、`办公室`、`委员会`、`政府`、`厅`、`局`、`集团`、`大学`、`学院`
- 如未命中特征词，则回退为日期前一候选段

### 3. 标题序号
依次使用：`一、` → `（一）` → `1.` → `（1）` → `①`
> ⚠️ 注意：`1.` 使用半角点 `.`；旧稿中的 `1．` 会由 WPS 宏规范化为 `1.`

### 4. 正文格式
- 仿宋_GB2312三号，不加粗，字体颜色显式黑色
- 自动行距，按标准稿 `line=360`，段前段后0行
- 两端对齐，首行缩进 `32pt`
- 英文使用 Times New Roman

### 5. 页眉页码
- 页眉：仿宋_GB2312
- 页码：宋体四号，页面底部居中；目录页自身的页脚页码为罗马数字页码，正文为普通阿拉伯数字页码，从 `1` 开始

### 6. 表格格式
- 标题：黑体小四，不加粗，居中，字体颜色显式黑色
- 内容：仿宋_GB2312约 `10.5pt`，整体加粗，字体颜色显式黑色，数字用 Times New Roman
- 自动行距 `line=360`，单元格居中，左右内边距 `5.4pt`，上下内边距 `0`
- 边框：上边框、下边框、内部横线、内部竖线为黑色单实线，左右外框线为无

### 7. 插图格式
- 标题：黑体小四，不加粗，居中
- 位于图下方，前后各空一行

## 🚀 快速开始

### VBA 宏（Word/WPS 内使用）

#### 支持的软件
- ✅ Microsoft Word 2010 或更高版本
- ✅ WPS Office 2019 或更高版本

#### 详细使用步骤

**第一步：准备工作**

**对于 Microsoft Word：**
1. 确认 Word 版本为 2010 或更高版本
2. 确保已启用宏功能（文件 → 选项 → 信任中心 → 宏设置）

**对于 WPS Office：**
1. 确认 WPS 版本为 2019 或更高版本
2. 启用宏功能（文件 → 选项 → 安全性 → 宏安全性）
3. 勾选"启用所有宏"或"禁用无数字签名的宏"

**第二步：选择合适的代码文件**

| 软件 | 推荐文件 | 备选文件 |
|------|---------|---------|
| Microsoft Word | `GongwenFormatter.bas` | `GongwenFormatter_WPS.bas` |
| WPS Office | `GongwenFormatter_WPS.bas` | `GongwenFormatter.bas` |

> 💡 **说明**：`GongwenFormatter_WPS.bas` 是专门优化的WPS兼容版本，当前直接按咨询报告标准稿口径执行封面、目录、正文层级和页码。

**第三步：导入 VBA 代码**
```
方式一：直接复制粘贴（推荐）
1. 按 Alt + F11 打开 VBA 编辑器
2. 插入 → 模块
3. 复制所选 `.bas` 文件的全部内容
4. 粘贴到代码窗口

方式二：导入文件
1. 按 Alt + F11 打开 VBA 编辑器
2. 文件 → 导入文件
3. 选择目标 `.bas` 文件
4. 点击打开
```

**第四步：运行宏命令**

1. 按 `Alt + F8` 打开宏对话框
2. 选择 `FormatGongwen` 或 `格式化公文`
3. 点击"运行"
4. 运行说明：
   - `GongwenFormatter.bas` 会弹出模式选择框
   - `GongwenFormatter_WPS.bas` 直接按标准稿口径执行，不再额外弹窗选择

## 📝 注意事项

1. **字体要求**：
   - 方正小标宋简体（封面标题）
   - 黑体（一级标题、目录一级条目、表题/图题）
   - 楷体_GB2312（二级标题、目录二级条目）
   - 仿宋_GB2312（三级及以下标题、正文）
   - Times New Roman（英文、数字）
   - 统一样式入口会显式设置字体颜色为黑色

2. **字体缺失处理**：
   - 程序会自动检测系统字体
   - 如字体缺失，会自动退化到相似字体
   - 建议安装所有必需字体以获得最佳效果

3. **序号格式**：
   - 使用静态文本，不使用 Word 自动编号
   - `1.` 必须使用半角点 `.`
   - 双引号与段落字体保持一致

## 补充规则（2026-04-06）

### 表格格式补充
- 政府交付模式未单列表格标准时，表格统一按公文格式执行。
- 参考文档《雄安新区大规模建设的投融资体制机制研究报告终稿20220325.docx》提取的稳定规则如下：
- 表格外框线、内部横线、内部竖线统一为黑色单实线。
- 线宽统一按 VBA 中的 `4` 处理。
- 单元格左右内边距约 `5.4pt`，上下内边距为 `0`。
- 单元格内容垂直居中。
- 表格单元格文字统一按样稿`表格样式`处理：仿宋_GB2312 约 `10.5pt`，整体加粗，西文和数字使用 `Times New Roman`。
- 表格单元格段落使用自动行距 `line=360`，不强制压成单倍行距。

### 目录与索引格式补充
- 目录、索引、图目录、表目录、图表目录已纳入格式化范围。
- 目录标题按黑体 `18pt`、居中、加粗、黑色处理。
- 目录一般只显示 `一、` 和 `（一）` 两级；`1.` 及以下层级原则上不进入目录。
- 一级目录条目按黑体 `14pt`、黑色处理，二级目录条目按楷体 `14pt`、黑色处理。
- 自动目录原有的右对齐制表位、点引导符和页码会保留。
- 目录页自身的页脚页码按 `upperRoman`（罗马数字）处理，并保持页面底部居中；目录条目中的目标页码仍保留右对齐制表位和点引导符。
- 正文页码按普通阿拉伯数字页码处理。

## 补充规则（2026-04-15）

### 封面识别补充
- 封面扫描逻辑改为前 30 段候选扫描，不要求标题、编制单位、日期必须连续相邻。
- 支持“标题 / 空行 / 编制单位 / 空行 / 日期”的封面布局。
- 支持多行标题，编制单位前的所有候选段统一按封面标题样式处理。
- 日期识别支持年月格式和完整年月日格式。
- 编制单位优先通过机构关键词识别，未命中时回退到日期前相邻候选段。
