## 🎯 使用方法

### 运行主格式化宏

1. 打开 Word/WPS 文档
2. 按 `Alt + F8` 打开宏对话框
3. 选择 `FormatGongwen` 或 `格式化公文`
4. 点击“运行”
5. 在模式选择对话框中选择：
   - 点击【是】→ GB/T 9704标准模式
   - 点击【否】→ 政府交付版模式
   - 点击【取消】→ 取消操作

### 手动应用样式

当使用以下宏时，也会弹出模式选择对话框：
- `ApplyLevel1ToSelection`
- `ApplyLevel2ToSelection`
- `ApplyLevel3ToSelection`
- `ApplyLevel4ToSelection`
- `ApplyLevel5ToSelection`
- `ApplyBodyToSelection`

## 🔧 技术实现

### 模式选择

通过 `SelectFormatMode()` 返回：
- `standard`
- `government`
- `""`（取消）

### 封面识别逻辑

```vba
- 扫描文档前 30 段
- 忽略空行和表格内容
- 收集前部短正文段落作为封面候选
- 从后向前识别日期段
- 在日期前优先匹配编制单位关键词
- 编制单位前的所有候选段统一作为封面标题
```
