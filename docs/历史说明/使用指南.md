# 🚀 使用指南 - 纯 VBA 版本

## 快速选择

**问：我应该用哪种模式？**

| 你的文档类型 | 推荐模式 |
|------------|---------|
| 党政机关公文、正式行政文件 | GB/T 9704标准 |
| 政府交付报告、咨询研究报告 | 政府交付版 ✨ |

---

## 使用方式

### 📄 VBA宏（Word/WPS内使用）

```
1. 导入宏文件
   - Word用户：GongwenFormatter.bas
   - WPS用户：GongwenFormatter_WPS.bas

2. 运行宏
   - 按 Alt + F8
   - 选择 "FormatGongwen" 或 "格式化公文"
   - 点击"运行"

3. 执行方式
   - Word用户运行 GongwenFormatter.bas：会弹出模式选择框
   - WPS用户运行 GongwenFormatter_WPS.bas：直接按标准稿口径执行，不弹窗

4. 等待格式化完成
```

## 两种模式的区别

### 视觉对比

#### GB/T 9704标准模式
```
        一级标题（居中）

  一、二级标题
  正文内容首行缩进...

  （一）三级标题
  正文内容首行缩进...
```

#### 政府交付版模式 ✨
```
        一级标题（居中）

一、二级标题
  正文内容首行缩进...

（一）三级标题
  正文内容首行缩进...
```

### 核心差异

| 标题级别 | GB/T 9704标准 | 政府交付版 |
|---------|--------------|-----------|
| 二级标题 | 左缩进2字符 | 首行缩进2字符 |
| 三级标题 | 左缩进2字符 | 首行缩进2字符 |
| 四级标题 | 左缩进2字符 | 首行缩进2字符 |

## 封面识别

当前版本支持：
- 封面中的空行分隔
- 多行标题
- `2026 年 4 月` 这类年月日期
- 编制单位关键词识别

示例：

```text
低空基础设施和信息服务行业研究报告

中咨海外咨询有限公司
2026 年 4 月
```

识别结果：
- 第一段：封面标题
- 第二段：编制单位
- 第三段：日期

## 常见问题

### Q1: 如何切换模式？
**A:** 如果使用 `GongwenFormatter.bas`，重新运行并重新选择模式即可；如果使用 `GongwenFormatter_WPS.bas`，当前固定按标准稿口径执行。

### Q2: 两种模式可以混用吗？
**A:** 不建议。一个文档应该统一使用一种模式。

### Q3: 如何判断文档当前是哪种模式？
**A:** 查看二级标题：
- 整个标题左移 → GB/T 9704标准
- 只有首行缩进 → 政府交付版

### Q4: VBA宏在WPS中能用吗？
**A:** 能。请使用 `GongwenFormatter_WPS.bas`，它现在会直接按标准稿处理封面、目录、正文层级和页码。

### Q5: 封面有空行或标题分成两行还能识别吗？
**A:** 能。当前版本会忽略封面中的空行，并支持多行标题识别。

### Q6: `2026 年 4 月` 这种没有“日”的日期能识别吗？
**A:** 能。当前版本支持 `年/月`、`YYYY-MM`、`YYYY/MM`、`YYYY.MM` 等格式。
