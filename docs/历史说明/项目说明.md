# 公文格式化工具 - 纯VBA版本

## 📌 项目说明

本项目是一个专业的Word文档自动化排版工具，**仅提供VBA宏版本**。

### ✨ 核心特性

- ✅ **双格式模式**：GB/T 9704标准 + 政府交付版
- ✅ **Word兼容**：Microsoft Word 2010+
- ✅ **WPS兼容**：WPS Office 2019+
- ✅ **一键格式化**：自动识别标题级别
- ✅ **字体兼容**：自动退化到可用字体

### 🚀 快速开始

1. **下载VBA宏文件**
   - Word用户：`GongwenFormatter.bas`
   - WPS用户：`GongwenFormatter_WPS.bas`

2. **导入到Word/WPS**
   - 按 `Alt + F11` 打开VBA编辑器
   - 插入 → 模块
   - 复制粘贴代码或导入文件

3. **运行宏**
   - 按 `Alt + F8` 打开宏对话框
   - 选择 `FormatGongwen`
   - 选择格式模式
   - 完成！
